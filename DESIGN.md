# MOUVRA visual system

The precision of an ordinary hand movement becomes a sculptural product showcase. One oversized official mouse floats over the word «Движение»; a still, editorial composition becomes tangible through a deliberate 3D control. The remaining page gives useful product choices, shape guidance and source-backed details.

60% warm ivory #F5F1E9, 30% stone #DDD5CB / pale taupe #E9E3DA, 10% oxblood #6E283A. Ink #272622, muted #69645E. User palette overrides automatic skill recommendations. Never add RGB/neon gaming styling.

Typography: Manrope variable for Russian interface and display, own-wordmark upper case tracking; occasional restrained serif for editorial statements using Cormorant Garamond. The dealt Panchang/Switzer pair lacks suitable Cyrillic support and is replaced for the Russian language requirement. Fluid headings 42–96px (oversized background word is decorative); body 16–18px, secondary 13–14px.

Layout: 64px desktop and 20px mobile frame; 1440px content maximum. Rounded 12px product surfaces, pill controls, dark oxblood focus/action. Object hero adapted from the supplied bag and headphone references. Product grid is functional catalogue content. Account and comparison use denser operational layouts and the same tokens.

Motion: 900ms hero image reveal, 180–320ms action feedback, 280ms route entry, interactive 3D on explicit action. No scroll hijacking. All content remains visible without reveal scripts; reduced-motion disables decorative transforms. Fully operable mobile navigation, form labels, focus trapping, keyboard model viewer, semantic table and labelled icon buttons.
