# MOUVRA: PHP, MySQL и демонстрация Docker

## Цель

Подключить существующий интерфейс MOUVRA к полноценному PHP API и постоянной базе MySQL. Добавить демонстрацию элементов Docker из «Лекция35_DevOps.pdf», чтобы проект можно было запустить и показать преподавателю.

## Предлагаемые технические решения

Это выбор исполнителя для согласования: PHP 8.3 с Apache, MySQL 8.4, PDO и Docker Compose. React-интерфейс сохраняется. Отдельная сборка интерфейса обслуживается Apache на одном origin с `/api`, поэтому не требуется междоменная авторизация. GitHub Pages сохраняет существующий статический демонстрационный режим; PHP-версия запускается отдельно на localhost:8080. Публикация на внешнем сервере не входит в эту работу.

## Функции

- Регистрация, вход, выход, просмотр аккаунта, изменение имени.
- Избранное и корзина сохраняются в MySQL и доступны после повторного входа.
- Сохранение заказов-подборок и их история. Оплата и доставка не добавляются: нынешний проект является каталогом, а не действующим магазином.
- Каталог импортируется из research/mice.json в MySQL. В PHP-режиме интерфейс получает каталог через API; статический режим использует текущий JSON.
- Обработка загрузки, ошибок сервера и пустых данных в интерфейсе.
- Объяснение Docker, API и базы данных хранится в документации проекта; отдельная учебная страница в интерфейсе не добавляется.

## Данные и API

Таблицы: users, sessions, auth_attempts, products, cart_items, favorites, orders, order_items, schema_migrations. У строк корзины и избранного уникальна пара пользователь/товар. Внешние ключи связывают записи; индексы поддерживают вход, сессии и историю пользователя. Цена хранится точным денежным типом, неизвестная цена — NULL. Заказ сохраняет снимок имени, цены и валюты товара на момент создания. Суммы разных валют считаются раздельно; неизвестные цены не превращаются в ноль.

Сохраняются контракты существующих /api/register, login, logout, account, state, profile, orders. Добавляются GET /api/products и GET /api/health. Заказы и пользовательские данные доступны только владельцу. Цены и итог рассчитывает сервер по БД. Обновление корзины/избранного и создание заказа выполняются транзакционно. Повторная отправка создания заказа с одним ключом идемпотентности возвращает прежний результат. Корзина после сохранения подборки остаётся, как в текущем интерфейсе.

Пароли хешируются password_hash; сессии используют случайный токен, в БД хранится только его хеш. Cookie HttpOnly, SameSite; Secure включается для HTTPS. Изменяющие запросы проверяют origin. Ограничиваются размер тела, поля, количество товаров и попытки входа. SQL выполняется через подготовленные запросы. Секреты задаются окружением и не коммитятся. Данные прежней Cloudflare D1 автоматически не переносятся; исходный код этого режима сохраняется.

## Docker и демонстрация лекции

Compose запускает web (PHP/Apache) и database (MySQL) в общей сети. MySQL не публикуется на хост; данные находятся в именованном томе. Healthcheck определяет готовность БД. Миграции и импорт каталога запускаются явными документированными командами и безопасны при повторении. Будут шаблон окружения, Dockerfile, compose.yaml, инструкция запуска, резервного копирования и восстановления.

Учебная инструкция сопоставит все семь компонентов Docker из лекции с проектом, объяснит FROM/COPY/EXPOSE, слои образа, жизненный цикл контейнера, изоляцию и ресурсы. Включит ответы на практические задания и контрольные вопросы, схему запуска и отдельный необязательный пример Nginx на другом порту. Команды удаления учебного контейнера не затрагивают том MySQL.

## Проверка результата

Проверить PHP syntax, миграции и повторный импорт; API-тестами проверить регистрацию, дубликат email, неверный пароль, истечение/выход сессии, доступ другого пользователя, валидацию и origin, сохранение состояния, серверные цены и идемпотентность заказа. Проверить сохранность данных после пересоздания контейнера без удаления тома. Выполнить текущие тесты, typecheck, lint и сборки интерфейса; в браузере пройти регистрацию → корзину → сохранение → повторный вход → историю. При недоступном Docker отдельно указать непроверенные сценарии, не объявлять их успешными.

## Граница готовности

Результат — рабочий локальный PHP/MySQL-проект с инструкцией и демонстрацией лекции. Почтовое восстановление пароля, платежи, склад, админ-панель и публичный production deployment в этот объём не входят. Конкретную структуру PHP-модулей и инструмент API-тестов выбирает исполнитель.
