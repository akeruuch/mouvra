# Лекция 54 в MOUVRA

В существующий проект добавлены Prettier и Stylelint. ESLint уже был подключён.
Проект использует React и TypeScript, поэтому проверяются также файлы TS и TSX.
Новый учебный сайт не создаётся: продолжается работа над MOUVRA.

## Настройки

В `.prettierrc.json` включены точки с запятой, одинарные кавычки, отступы
в 4 пробела и завершающие запятые. `endOfLine: lf` позволяет использовать одинаковые
переносы строк в Windows и Linux.

`.prettierignore` исключает сборки, зависимости, рабочие материалы, исходные
исследовательские данные и сторонние компоненты. Собственный код приложения,
конфигурации, тесты и документация проверяются. PHP остаётся в существующем
оформлении: стандартный Prettier не форматирует PHP без отдельного плагина.

## Команды

```sh
npm ci
npm run format:check
npm run format
npm run lint:css
npm run lint
npm run typecheck
npm test
```

`npm run check` выполняет проверку оформления, Stylelint, ESLint, проверку типов
и тесты. `format:check` ничего не изменяет, `format` переписывает оформление файлов.

## Расширения VS Code

Установлены `esbenp.prettier-vscode`, `dbaeumer.vscode-eslint`
и `stylelint.vscode-stylelint`. Они перечислены в `.vscode/extensions.json`.
В `.vscode/settings.json` выбран Prettier и включён `editor.formatOnSave`.
В режиме Restricted Mode расширения могут быть ограничены: доверие к знакомой
папке пользователь включает самостоятельно через Manage Workspace Trust.

Расширение редактора и npm-зависимость отличаются. Расширение работает в VS Code,
а локальная зависимость нужна для терминала и GitHub Actions.

## GitHub Actions

`.github/workflows/format-check.yml` проверяет оформление, CSS, JavaScript,
TypeScript, тесты и сборку статической версии. Запуск происходит при push
в `main` или `codex/mouvra-continuation`, а также при pull request в `main`.
Установка зависимостей выполняется через `npm ci` по `package-lock.json`.

## Предыдущие работы

В MOUVRA сохранены PHP и MySQL, регистрация, вход, корзина, избранное и подборки.
Отзывы привязаны к товарам и настоящим аккаунтам. Гость может читать отзывы,
зарегистрированный пользователь — поставить оценку от 1 до 5 и написать отзыв.
Редактировать и удалять отзыв может только его автор; это проверяется на сервере.
На GitHub Pages серверных аккаунтов и отзывов нет: их нужно показывать
в PHP-версии по адресу http://127.0.0.1:8080.

Пояснения к устройству проекта находятся в `docs/CODE_GUIDE.md` и комментариях
рядом с обработчиками интерфейса и API.

## Как объяснить преподавателю

Я продолжил сайт MOUVRA. В нём уже были сервер на PHP, база MySQL и отзывы
со звёздами. По лекции 54 я добавил Prettier, чтобы автоматически исправлять
оформление кода. ESLint ищет проблемы в JavaScript и TypeScript, а Stylelint —
в CSS. Я проверил, что Prettier замечает неправильные отступы, затем исправил
их и добавил автоматическую проверку в GitHub Actions. После форматирования
проверил тесты, сборки и работу отзывов в браузере.
